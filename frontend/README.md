# Math Mentor(Frontend)

## 1. Go to frontend directory.
```
cd frontend
```

## 2. Make sure node is installed to your system.
You can download and install node from here [link](https://nodejs.org/en/download)

## 3. Install all the required library.
```
npm insall
```

## 4. Create a .env.local file on the frontend directory and copy the followings to that file.
```
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000/api
NEXT_PUBLIC_MEDIA_BASE_URL=http://127.0.0.1:8000
```

### 5. Run the dev server and make sure that the backend server is running also.
```
npm run dev
```
